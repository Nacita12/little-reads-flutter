# Little Reads

## Deskripsi Aplikasi
Little Reads adalah aplikasi mobile berbasis Flutter yang menampilkan berita dari API. Aplikasi ini memiliki tampilan pastel dan dirancang agar pengguna dapat mencari serta membaca informasi berita dengan mudah.

## Fitur Utama
- Menampilkan daftar berita dari API.
- Mencari berita berdasarkan judul.
- Melihat detail berita.
- Membuka artikel lengkap melalui situs sumber berita.
- Menyimpan berita ke daftar favorit.
- Menampilkan indikator loading dan pesan error jika berita gagal dimuat.

## Teknologi dan Package
- Flutter
- Dart
- `http` untuk mengambil data dari API.
- `url_launcher` untuk membuka tautan berita.
- `dart:convert` untuk parsing JSON.

## Cara Menjalankan Aplikasi
1. Instal Flutter SDK dan Android Studio.
2. Clone repository ini atau unduh source code-nya.
3. Buka folder project melalui Android Studio.
4. Jalankan perintah `flutter pub get` pada terminal project.
5. Jalankan aplikasi menggunakan emulator Android atau perangkat yang terhubung.

## API
Aplikasi mengambil data berita dari FreeNewsAPI. Ketersediaan data bergantung pada layanan API dan koneksi internet.
